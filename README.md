# Зал и бег

Мобильный журнал 12-недельной программы. Программа и техника упражнений находятся в `worker/program.js`, пользовательский журнал хранится в D1. Интерфейс поддерживает прежний формат записей и экспорт JSON.

## Сборка

```sh
node build.mjs
node --check dist/server/index.js
```

Для развёртывания нужен Cloudflare Worker с привязкой D1 под именем `DB`. Схема базы находится в `drizzle/0000_journal.sql`. Приложение рассчитано на приватный OpenAI Sites или эквивалентный доверенный слой авторизации, который удаляет присланный клиентом заголовок `oai-authenticated-user-id` и проставляет проверенный идентификатор пользователя. Для подключения к Sites добавь идентификатор своего проекта в `.openai/hosting.json`.

Исходный код не содержит пользовательских записей из облачной базы. Для их переноса используется экспорт и импорт в разделе «История».
